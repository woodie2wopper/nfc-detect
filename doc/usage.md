# NFC Detect 使用方法と注意点

## 音声ファイルの仕様

### 対応フォーマット
- librosaが対応しているフォーマット（libsndfileがサポートする形式）
- 詳細な対応フォーマットは以下を参照：
  http://www.mega-nerd.com/libsndfile/#Features

### ファイル長の制限
- 現在の実装では、長いファイルを一度に処理するとメモリ不足になる可能性があります
- 推奨される使用方法：
  - 10分程度ずつに区切って処理
  - ファイルを分割する必要はありません
  - `--duration`を600（10分）として、`--start`を0, 600, 1200, ...のように順次処理

## データセットの作成

### アノテーションの仕様
- 音声の開始時刻前の余白について考慮する必要はありません
- 訓練データ作成時の処理：
  - アノテーション音声の長さが指定されていればその長さを使用
  - 長さが指定されていない場合は200msと仮定
  - 音声が1秒間のセグメントの中心付近に来るように切り出し処理

## 録音に関する知見

### 録音方法の検討事項
1. 環境ノイズの影響
   - 虫の音
   - 自動車の音
   - その他の環境音

2. 録音機器の設定
   - 圧縮率
   - 電池の持ち
   - 機器の収納方法（袋に入れる影響など）

3. 音質評価
   - SN比（信号対雑音比）の影響
   - 音圧と距離の関係
   - モニタリング可能な範囲の定量評価

## トラブルシューティング

### Apple Silicon (M1/M2) Macでの問題
1. ターミナルの実行環境確認
   ```bash
   arch
   ```
   - `arm64`と表示されることを確認
   - `i386`と表示される場合は、Rosetta環境で動作しているため、native環境に切り替えが必要

2. Python環境の確認
   - Activity MonitorでPythonプロセスのCPU種別を確認
   - "Apple"と表示されていればnative環境
   - "Intel"と表示されていればRosetta環境

3. GNU coreutilsの影響
   - coreutilsがインストールされている場合、PATHから外すことを推奨
   - これにより、正しいアーキテクチャのバイナリがビルドされる
